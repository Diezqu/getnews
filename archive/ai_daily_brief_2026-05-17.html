📄 arXiv 最新论文

cs.AI · cs.CL · cs.MA
AI Knows When It's Being Watched: Contextual Register Modulation in LLMs
Vinicius Covas, Jorge A. H. Toledo · 2026-05-14 · cs.CL / cs.AI / cs.MA
【中文摘要】研究证明 LLM 多 Agent 系统存在"霍桑效应"——在被人类研究者监控时，Agent 的语言复杂度（TTR）显著上升 +24.9%；换成 AI 审计系统也达 +22.2%。AI 会根据"被谁观察"来调整自身行为，人类监督比自动化监控更能触发规范化表达。对 AI 治理与审计具有直接意义。
Multi-Agent AI Governance Hawthorne Effect
Cattle Trade: A Multi-Agent Benchmark for LLM Bluffing, Bidding, and Bargaining
Robert Müller, Clemens Müller · 2026-05-14 · cs.AI · ICLR 2026 Workshop
【中文摘要】将竞拍、虚张声势、讨价还价、对手建模融入单个 50-60 轮博弈的综合性多 Agent 基准。测试 7 个 LLM 和 3 个启发式 Agent，"战略一致性"（资源纪律、阶段自适应出价）比单一子技能更能预测排名。两个启发式 Code Agent 超过大多数 LLM，揭示当前 LLM 在多能力联合部署上的缺陷。
Benchmark Strategic Reasoning Game Theory
MARLIN: Multi-Agent Game-Theoretic RL for Sustainable LLM Inference
H. Moore, S. Qi, D. Milojicic, C. Bash, S. Pasricha · 2026-05-13 · cs.DC / cs.LG
【中文摘要】提出多 Agent 博弈论强化学习框架，同时优化 LLM 推理的首 Token 时间（TTFT）、碳排放、用水量和能耗。相比现有方案：TTFT 降低 ≥18%，碳排放 -33%，用水量 -43%，能耗 -11%。云数据中心绿色 AI 推理的重要突破。
Green AI RL Cloud Inference
MCP-Cosmos: World Model-Augmented Agents for Complex Task Execution in MCP Environments
arXiv:2605.09131 · 2026-05 · cs.AI
【中文摘要】将生成式世界模型（WM）注入 MCP 生态，使 Agent 具备任务执行前的预测推理能力，填补了"任务级规划忽略执行动态"与"反应式执行缺乏长远预见"之间的鸿沟。为 MCP Agent 引入预判与适应机制，显著提升复杂任务成功率。
MCP World Model Planning
Separating Intelligence from Execution: A Workflow Engine for the Model Context Protocol
arXiv:2605.00827 · 2026-05 · cs.AI
【中文摘要】提出 MCP 原生编排层，将"智能（决策）"与"执行（调用工具）"解耦。Agent 只需推理一次生成 JSON 声明式工作流蓝图，再由执行引擎逐步调用 MCP 工具，降低重复推理成本，提升 Agent 可调试性与复用性。

OpenHuman
👤 tinyhumansai GitHub Trending 5/13-17
本地优先的个人 AI 超智能，每 20 分钟从所有连接应用拉取新数据，压缩进本地 SQLite 知识树，让 AI 始终掌握你完整的工作上下文。Rust + Tauri 构建，GPL-3.0，完全私有无云端上传。
💡 为什么值得关注：没有云端、没有数据上传，AI 超智能真正属于个人。在隐私敏感时代这是稀缺品，连续多天登上 GitHub Trending。
🔀
Re_gent — Git for AI Agents
👤 doshay Show HN · 44pts · 26 评论
为 AI Agent 的每一步操作提供类 Git 的版本控制。支持 /rewind 回滚 Agent 决策、bisect 定位"是哪步操作破坏了文件"、追踪每个操作的"为什么"，目前已支持 Claude Code。
💡 为什么值得关注：Agent 操作越来越复杂，"为什么删了这个目录"是每个 AI 编程用户遇过的困惑。Re_gent 是首个正式解决此问题的开源工具，2026-05-17 Show HN 活跃讨论中。
📊
DAC — Dashboard As Code
👤 karakanb (Burak) Show HN · 33pts
用 YAML + JSX 定义仪表板的开源工具，所有配置版本可控，Agent 可直接生成和修改。单 Go 二进制部署，支持 10+ SQL 后端，内置语义层统一指标定义，动态图表和多租户支持。
💡 为什么值得关注：BI 工具一直是 Agent 的死角——UI 驱动无法程序化操控。DAC 把数据可视化变成可版本控制的代码，让 Agent 终于能"自动建仪表板"。
📱
BrightBean Studio
👤 JanSchu Show HN · 88pts · 64 评论
solo 开发者用 Claude Code + Codex 仅用 3 周构建的社媒管理平台：12 个一方 API 集成（FB/IG/LinkedIn等）、多租户 Auth、加密凭证、审批流、统一收件箱。Django + HTMX + PostgreSQL，AGPL-3.0。
💡 为什么值得关注：真实展示了 2026 年 solo 开发者借助多 Agent 并行开发的天花板——同时跑 4 个 Agent Worktree，3 周完成原本需要一年的工程量，含详细架构文档。
⚡
Superpowers — Agentic Skill Framework
👤 obra GitHub Trending 2026-05-17
专为编码 Agent 设计的软件开发方法论与技能框架，提供可组合的 Skill 模块和标准化初始指令，指导 Agent 按结构化流程完成软件创建，模块化设计支持自由组合扩展。
💡 为什么值得关注：不只是工具，而是"怎么用 Agent 开发软件"的方法论——对想系统化使用 Claude Code 的开发者有直接参考价值，今日 GitHub Trending 新登榜。
