📄arXiv 最新论文 · Agent & LLM

5 papers · 24h
1
Cattle Trade: A Multi-Agent Benchmark for LLM Bluffing, Bidding, and Bargaining
👥 Robert Müller, Clemens Müller 🔖 arXiv:2605.14537 Benchmark Multi-Agent
将拍卖、隐藏交易、谈判、虚张声势、对手建模、资源分配整合到 50-60 回合的单一长 horizon 博弈中，评测 7 个低成本 LLM + 3 个确定性代码 Agent 共 242 场比赛，记录每一次出价与反提议——把博弈论真正接入 Agent 评测。
2
VibeServe: Can AI Agents Build Bespoke LLM Serving Systems?
👥 Keisuke Kamahori, Shihang Li, Simon Peter 🔖 arXiv:2605.06068 Agent Infra
首个端到端生成 LLM 推理栈的 Agent 循环：外层规划系统设计，内层实现+验证+测性能。在非标准模型架构、特定工作负载和硬件优化场景下，跑赢通用推理框架——Agent 第一次开始"造工具"。
3
Predictive Maps of Multi-Agent Reasoning: A Successor-Representation Spectrum for LLM Topologies
👥 Ethan Parks, Dalal Alharthi 🔖 arXiv:2605.11453 Multi-Agent
为多 Agent LLM 通信图（chain/star/mesh）提供首个结构性诊断工具，基于继承表示推导闭式谱，并在 Qwen2.5-7B 的 12 步状态追踪任务上验证 100 次独立试验——为多 Agent 拓扑选型提供量化依据。
4
MARLIN: Multi-Agent Game-Theoretic RL for Sustainable LLM Inference in Cloud Datacenters
👥 H. Moore, S. Qi, D. Milojicic 🔖 arXiv:2605.13496 Multi-Agent Infra
LLM 推理请求贡献了全生命周期 90% 的能耗，远超训练成本。MARLIN 用博弈论 + 多智能体强化学习协同优化 TTFT、碳排放、用水量和能耗：TTFT 降 18%，碳 ↓33%，水 ↓43%，能耗 ↓11%——Agent + 绿色 AI 的代表作。
5
Constraint Decay: The Fragility of LLM Agents in Backend Code Generation
👥 Francesco Dente, Dario Satriani, Paolo Papotti 🔖 arXiv:2605.06445 Agent Eval
系统性研究 LLM Agent 处理结构性约束的崩塌现象：在 8 个 web 框架、80 个全新生成任务 + 20 个增量任务中，随着架构/数据库/ORM 等约束累加，Agent 性能显著退化——给应用层落地敲响警钟。
